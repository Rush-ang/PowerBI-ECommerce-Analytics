# 📊 Multi-Channel E-Commerce & Inventory Analytics Dashboard (Power BI)

![Power BI Banner](Daily%20order%20%26%20Return.png)

## 📌 Project Overview
An enterprise-grade **Power BI Analytics Solution** designed to track, analyze, and optimize multi-channel e-commerce operations across 8+ major marketplaces: **Amazon, Flipkart, Myntra, Ajio, Firstcry, Tatacliq, Meesho, and Shopify**.

This project provides real-time visibility into **₹20+ Cr in gross revenue**, tracking **20,000+ monthly orders**, return root causes, inventory ledger movement, stock aging (0–90+ days), and ad traffic conversion performance.

---

## 🌟 Key Features & Dashboard Modules

### 1. 🛍️ Order & Revenue Summary (Channel Level & Daily Breakdown)
* Multi-channel consolidation of Orders, Sales Revenue, Average Selling Price (ASP), and Daily Run Rate (DRR).
* Breakdown by marketplace fulfillment models (**MYCC, PPMP, MYOM, SJIT**).
* Multi-year and month-over-month sales performance comparison.

### 2. 🔄 Return Reason & Root Cause Analytics
* Categorization of return reasons: *Wrong Item Sent, Size/Fit Issues, Product Defects, Price Mismatch, Customer Remorse, Courier Logistics Failures*.
* Visual SKU photo gallery linked directly to return counts for rapid quality-control feedback.
* Breakdown of **RTO (Return to Origin)** vs **Customer Return** percentages per channel.

### 3. 📦 Inventory Ledger & Aging Tracking
* Complete inventory ledger covering **100,000+ units of opening stock**.
* Stock movement tracking: *Inward (+), Putaway (+), Returns (+), Gatepass (-), Sales (-), Adjustments (+/-)*.
* Inventory aging categorization: **0–15 Days, 15–30 Days, 30–45 Days, 45–60 Days, 60–90 Days, and 90+ Days**.

### 4. 📈 Ad Traffic & Conversion Performance Matrix
* 2x2 matrix visual classifying SKUs based on ad performance:
  - **High Consideration, High Conversion:** Top performing products.
  - **High Consideration, Low Conversion:** High interest; requires pricing or listing optimization.
  - **Low Consideration, High Conversion:** High conversion rate; needs increased ad spend/visibility.
  - **Low Consideration, Low Conversion:** Underperforming listings requiring review.
* Metrics tracked: Views, Clicks, CTR %, Orders, CVR %, Click per Order, Category CTR/CVR benchmark comparison.

### 5. 🎛️ Dynamic Slicers & Parameterized Selection
* Slicers for **Master SKU, Style Code, Brand Name, Sales Category, Category, Channel, Zone, and State**.
* Dynamic **Row & Value Selection toggles** for seamless metric switching via DAX.
